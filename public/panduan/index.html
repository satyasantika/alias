Panduan Alias FKIP

Alias FKIP memendekkan tautan panjang menjadi alamat resmi fakultas dan mencatat klik secara anonim. Pilih panduan sesuai peran Anda; setiap langkah dilengkapi tangkapan layar.

Panduan Pengguna

Dosen & tendik: buat tautan, QR, statistik.

Panduan Pengelola Unit

Admin prodi/unit: kelola tautan dan anggota unit.

Panduan Admin Alias

Operator: persetujuan, moderasi, pengguna, impor.

Panduan Pemantau (Pimpinan)

Pimpinan: statistik agregat saja.

Panduan Super Admin

TI fakultas: pengaturan, log login, Horizon.
